# 战双剧情排行

把《战双帕弥什》的剧情排成你自己的榜单。

## 功能

- **两两对比** —— 每次只给两张，选哪张更好，几十次点击就能排出整张榜
- **拖拽排序** —— 按住 ⋮⋮ 上下拖，拖到屏幕边缘会自动滚
- **搜索定位** —— 打章节名，匹配的高亮并自动跳过去
- **打乱** —— 拿不准顺序时先洗一遍
- **看大图** —— 点缩略图放大
- **导出** —— 文字排名，或整张榜的长图

## 说明

- 顺序记在浏览器本地，换设备不同步
- 纯静态页面，没有后端，不收集任何数据
- 图源：《战双帕弥什》WIKI「画册 / 登录界面」，共 59 张，版权归库洛游戏所有，此处仅作同人非商业展示
